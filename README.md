# NEXUS — Productivity Command Center

A futuristic productivity dashboard built using **HTML, CSS and JavaScript**.

NEXUS is designed as a modern **Productivity OS** that brings tasks, goals, focus sessions, notes and productivity analytics together in one interactive dashboard.

---

## 🚧 Project Status

**Version 1.0 — Core Features Complete 🚀**

NEXUS is currently a fully functional frontend productivity dashboard with persistent local data, interactive productivity modules and responsive design.

## 💾 Data Persistence

NEXUS uses the browser's **Local Storage API** to persist user data.

The following information can be stored locally:

- Tasks
- Goals
- Notes
- Focus time
- Productivity streak
- Weekly activity
- Theme preference

No external database is currently required.
